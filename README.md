⚡️ Electronics Store App — Flutter UI

Welcome to the Electronics Store Flutter Application, a modern, cross-platform mobile application built using Flutter.
This project focuses on the frontend implementation of a fully responsive e-commerce app for electronic products, featuring elegant UI screens for Home, Products, Categories, Checkout, Login/Register, and Profile.

📱 Overview

This project serves as a frontend-only prototype for an electronics store mobile application.
The app provides a visually rich, intuitive interface designed with modern Flutter widgets and best UI/UX practices.

It showcases how an electronics e-commerce app might look and behave before backend integration or state management is applied.

✨ Features
🏠 Home Screen

Beautifully designed home layout with responsive banners and featured products.

Promotional sliders and category shortcuts.

Highlights of trending, best-selling, and new arrival products.

🛍️ Product Listing & Filters

Grid and list views for displaying products.

Interactive product cards showing images, prices, and quick actions (wishlist/add to cart).

Category-based and filter-based browsing (e.g., price range, brand, rating).

🔎 Categories Screen

Clean and organized product categories such as Laptops, Smartphones, Headphones, Smartwatches, etc.

Category-specific filtering options and dynamic banners.

💳 Checkout Screen

Minimalist and user-friendly checkout process UI.

Includes sections for address details, order summary, and payment options (UI only).

Progress indicators showing checkout steps.

👤 Login & Register Screens

Fully designed authentication flow with form validation (frontend only).

Separate login and registration pages with consistent design language.

Placeholder for integration with Firebase/Auth APIs.

👨‍💼 Profile Screen

Displays user info, order history (mock data), and settings shortcuts.

Option to edit profile details and log out (frontend logic placeholder).
